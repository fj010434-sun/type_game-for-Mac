# 两套换装视觉样板实施计划

## 样板设计

- 日常执勤：浅蓝短袖、翻领与领带、肩章、直筒裤、低帮执勤鞋。
- 巡逻夹克：深蓝长袖、立领与拉链、拼接肩部、袖口、侧袋裤、明显高帮短靴。
- 保留现有身体比例、帽子和圆润风格；两套共用原有骨骼、原始动画、经验与解锁规则，部件可以混搭。
- 原始七骨骼没有肘膝关节，新增服装按现有整段肢体运动设计，不宣称增加细分关节或布料模拟。
- 面部与发型改善可见差异；分类缩略图聚焦实际部位，头发卡片使用无帽参考并明确标注。

## 实施顺序

1. 保存原版参考图；新增游戏尺寸轮廓差异和动画绑定回归检查，先确认测试能揭示原有问题。
2. 安装 Blender 制作工具；采用 blender-image-to-3d 的轮廓优先、共骨骼、极限姿势及导出回读方法，保留制作脚本与 .blend 主文件。原有模型为比例与骨骼参考，新服装结构为原创设计。
3. 导出独立衣袖、领型、裤袋与鞋帮几何，保持有效且归一的骨骼权重；接入现有人物装配器并正确释放资源。
4. 增加两套样板对照页，支持同步站立、行走、冲刺、抓捕、旋转；改进衣柜分类近景。
5. 在游戏尺寸、灰色材质、正侧背及完整动作周期查看两套效果；检查混搭与切换。自动测试不能代替人工美术判断。
6. 完成全套现有自动测试、原生应用构建和原生换装抓捕检查；保存对照图、演示视频和验证记录。不自动推送或替换已安装应用。
