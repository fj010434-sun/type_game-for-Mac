# 第二批换装素材验收

新增十件，总数31。900经验解锁贝雷帽、卷短发、英气眉；1200解锁专注眼、含笑嘴、护膝裤；1550解锁棱角脸、挺直鼻、反光马甲、高帮靴。旧21件及解锁条件保留，旧存档继续使用。

制作遵循既有低多边形人物的比例、配色和灯光。马甲前后都有立体反光条，护膝和高帮靴使用对应腿骨，贝雷帽使用不对称帽冠。服装使用原人物骨骼与32个原动作，未新增关节、动作或布料模拟。第三套完整素材见 `art/wardrobe/traffic.glb` 和 `traffic.blend`；从实际游戏装配器导出，经 Blender 4.5.3 回读检查并保存可编辑主文件。
