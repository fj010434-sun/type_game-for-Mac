## 检查入口

启动 `python3 devserver.py`，执行 `BASE_URL=http://127.0.0.1:8765 ./tests/run-all.sh`。

- `tests/world-cities.cjs`：七城保存、七城 × 三种警察、音乐主题和最小窗口。
- `tests/city-navigation.cjs`：已保存地点滚动定位、静音保持和键盘焦点。
- `tests/city-music.test.mjs`：声部和节奏差异、可播放音符。
- `tests/city-render.cjs`：OfflineAudioContext 音频渲染、削波检查、实际游戏镜头截图，以及前方地标保留和最终回收。

`*-world.png` 为实际游戏镜头的纯世界图，其他城市名图片含游戏 HUD；前者由独立 World 实例定位到指定路段，后者来自实际开始追逐。它们不等于人工音频试听或全部真实路线的人工体验。
